# 更新日志

## 0.2.0

### 新增

- **版本更新日志**：新版本首次打开时自动展示更新日志，可在「帮助 → 更新日志」手动查看。
- **ark_disasm 内置分发**：随安装包内置 `ark_disasm` 二进制，开箱即用，无需额外配置。
- **反汇编视图**：支持 `.abc` / `.hap` / `.har` 文件的 ArkDisasm 反汇编结果展示。
- **AI 助手**：集成 AI 对话能力，支持基于当前反汇编内容进行智能问答。
- **全局搜索**：跨文件的关键字搜索与结果定位。
- **导出能力**：支持将反汇编结果导出为文件。
- **资源文件预览**：支持在资源树中直接预览图片（`.png` / `.jpg` / `.jpeg` / `.webp`）、JSON（`.json`）与配置信息（`.info`）文件，图片自动解码渲染，JSON / `.info` 自动格式化展示。
- **资源文件导出**：图片资源可导出原始文件，JSON / `.info` 文本资源可导出原始内容，保留原始格式与质量。

### 改进

- 优化编辑器标签管理与多视图切换体验。
- 完善项目树的定位（Reveal）与文件导航交互。
- 资源树对不同类型资源节点（图片 / 文本 / 配置）提供差异化工具栏操作与导出入口。

### 修复

- 修复部分场景下标签切换状态不一致的问题。
